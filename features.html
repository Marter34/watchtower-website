Protection and Control

Watchtower Features

Moderation and security tools designed to help Discord communities manage their servers, respond to threats, and maintain a safer environment.

Everything in One Place

Watchtower is designed for different communities, from small friend groups to large public servers.

📝

Moderation Commands

Manage common moderation tasks with tools for warnings, timeouts, kicks, bans, and message cleanup.

  • Warning management
  • Member timeouts
  • Kick and ban actions
  • Bulk message cleanup
🛡

Anti-Raid Protection

Designed to detect suspicious waves of new members and help administrators respond to coordinated raids.

  • Configurable join thresholds
  • Suspicious activity detection
  • Emergency response planning
  • Administrator review
🔒

Anti-Nuke Protection

Designed to help protect servers from destructive administrative actions and unauthorized changes.

  • Destructive-action monitoring
  • Emergency lockdown concept
  • Restricted recovery controls
  • Security event recording
🔔

Security Logging

Keep track of relevant moderation actions and security events for administrator review.

  • Moderation action records
  • Security event history
  • Configurable log destinations
  • Incident review support
⚙

Server Configuration

Configure protection policies to suit the needs and activity levels of each Discord community.

  • Per-server settings
  • Adjustable detection thresholds
  • Permission-aware management
  • Central dashboard design
🔒

Controlled Recovery

Emergency protection should include deliberate recovery procedures to reduce accidental damage.

  • Restricted recovery actions
  • Administrator authorization
  • Configuration validation
  • Review before restoration

Moderation Tools

Give authorized moderators tools to respond to rule violations consistently.

Tool Purpose Access
Warnings Record and review member warnings. Authorized moderators
Timeout Temporarily restrict a member's communication. Authorized moderators
Kick Remove a member from the server. Authorized moderators
Ban Ban a member when warranted. Authorized moderators
Purge Remove a specified batch of messages. Authorized moderators

Availability depends on the bot implementation, Discord permissions, and the commands enabled on the server.

Designed with Safety in Mind

Security features should not become another source of disruption for the communities they protect.

Configurable Detection

Thresholds should be adjustable to account for differences in server size and normal activity.

Permission Checks

Sensitive actions should be restricted to appropriately authorized users.

Accountable Actions

Relevant actions should be recorded to support troubleshooting and administrator review.
