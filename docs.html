01 / SETUP

Getting started

Follow these steps to add Watchtower to a Discord server. Some features may depend on the commands and configuration currently available in the deployed bot.

01

Invite Watchtower

Use the official invite link and select the server where you have permission to add bots.

Invite Watchtower
02

Review permissions

Review the requested permissions carefully. Only grant the permissions needed for the moderation features you intend to use.

03

Test the bot

Open your server and check whether Watchtower appears online. Try an available slash command in a private test channel before using moderation tools publicly.

02 / PERMISSIONS

Bot permissions

Discord permissions control what Watchtower can do. A bot cannot moderate members or manage channels when it lacks the required permissions.

Permission Purpose
View Channels Allows the bot to see channels it has access to.
Send Messages Allows the bot to respond in permitted channels.
Read Message History Allows access to previous messages where needed.
Moderate Members Required for member timeouts.
Kick Members Required to kick members.
Ban Members Required to ban members.
Manage Messages Required for deleting messages during moderation.
Manage Channels Needed for channel-locking actions that change channel permissions.

Important: Discord role hierarchy also matters. Watchtower generally cannot moderate a member whose highest role is equal to or higher than the bot's highest role.

04 / SECURITY

Protect your server

01

Use least privilege

Give staff only the permissions needed for their responsibilities. Review bot permissions periodically.

02

Protect staff accounts

Encourage two-factor authentication and never share account passwords, bot tokens, or secret keys.

03

Prepare for emergencies

Decide who can respond to raids, where incidents should be reported, and how your team will verify recovery actions before changing permissions.

Automated security features are not a substitute for active moderation. Review important actions, test configuration changes safely, and keep a separate plan for incidents.

05 / TROUBLESHOOTING

Common problems

Watchtower is offline

Check the status page for backend health information. An online website backend does not necessarily mean the Discord bot is connected. If the issue continues, contact support.

A command does not appear

Confirm that Watchtower is in the server, that its application commands are available, and that you have permission to use the command. Some changes may take time to appear in Discord.

A moderation action fails

Check the bot's permissions, the target member's role hierarchy, and your own access to the command. Discord may reject actions that exceed the bot's authority.

The website dashboard does not save settings

Dashboard controls may not be connected to a working configuration backend yet. Do not assume a setting was saved unless the dashboard explicitly confirms success.

06 / SUPPORT

Need more help?

If you run into a problem, gather the command name, a brief description of what happened, and any relevant error message. Never include passwords, bot tokens, or other secret credentials in a support request.
