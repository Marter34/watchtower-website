Quick start

  1. Invite Watchtower using the invite button.
  2. Review the requested permissions in Discord.
  3. Place the bot's role above roles it needs to moderate, but below trusted administrator roles.
  4. Configure staff roles, logging channels, and emergency settings supported by your deployed bot.
  5. Test in a private server before relying on protection in a live community.
Permission warning: The current invite URL requests Administrator permission. Consider generating a least-privilege invite based on the permissions the bot actually needs.

Anti-raid protection

Anti-raid systems can watch for unusually fast waves of new members. Choose thresholds based on your server's normal join rate and avoid settings that automatically punish members without review.

  • Set a reasonable join threshold and detection window.
  • Choose whether a trigger alerts staff, enables verification, or requests a temporary lockdown.
  • Document how staff can reverse mistaken actions.
  • Test during a controlled event before enabling automation.

Anti-nuke lockdown

Anti-nuke protection aims to respond to suspicious destructive activity such as mass channel or role changes. Automated actions can cause damage if configured too aggressively.

  • Keep an owner-controlled recovery path outside the bot.
  • Restrict sensitive controls to trusted administrators.
  • Log trigger events and responses where technically possible.
  • Test lockdown and restoration in a separate server.
  • Do not assume deleted messages or channels can always be restored exactly.

Moderation commands

Only use commands implemented by the deployed version of Watchtower. Slash-command names, options, and permissions can differ by release.

Use the commands available in your Watchtower server. Only trusted staff should have access to moderation commands.

For each command, document who can use it, required arguments, what it changes, whether it can be reversed, and where the action is logged.

Troubleshooting

Bot appears offline: Check that Watchtower is online in Discord and try again in a moment.

Missing permissions: Check role hierarchy, channel-specific overrides, and the invoking member's permissions. Avoid granting Administrator as the first troubleshooting step.

Support: Join the Watchtower support server or use the support contact provided by the project operator.
