Understanding Status

These indicators describe what the website can verify. They do not automatically confirm every bot feature is working.

✓

Online

The backend health endpoint responded with a status recognized as online by the website.

!

Unavailable

The request failed, the server returned an error, or the response did not confirm availability.

i

Limited Information

Bot latency, Discord gateway connectivity, uptime, and server count require additional backend reporting.
